# Valen — Site 2026

Redesign do site institucional da Valen, preservando a arquitetura do site anterior e evoluindo a experiência visual para uma direção editorial, tecnológica e orientada por motion.

## Stack
- HTML5 semântico
- CSS responsivo
- JavaScript vanilla
- GSAP + ScrollTrigger (CDN)
- Deploy estático na Vercel

## Estrutura preservada
Hero → Sobre → Desafios → Método → Soluções → Princípios → Carreiras → Contato.
